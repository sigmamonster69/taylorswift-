# Taylor Swift: The Eras Edit 🎵✨

A vibrant, pink-themed Taylor Swift fan site created as a university CTF (Capture The Flag) challenge. Explore Taylor's musical journey through her iconic eras with a responsive, beautifully designed interface.

![Taylor Swift Eras Badge](eras-badge.png)

## 🌟 Features

- **Responsive Design**: Looks great on desktop, tablet, and mobile devices
- **Era Guide**: Comprehensive overview of Taylor's studio albums and their unique aesthetics
- **Starter Playlist**: Curated song recommendations for new listeners
- **Modern Web Technologies**: Built with semantic HTML5, CSS3 Grid, Flexbox, and custom properties
- **CTF Challenge**: Find the hidden flag in the HTML source comments!

## 🎨 Design Highlights

- Custom color palette with pinks, purples, and peach tones
- Google Fonts integration (DM Mono & Playfair Display)
- CSS animations and hover effects
- Layered gradient backgrounds
- Pseudo-elements for decorative effects
- Accessibility-focused markup

## 🚀 Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, or Edge)
- No build tools or dependencies required!

### Running Locally

1. Clone this repository:
   ```bash
   git clone <repository-url>
   cd <repository-directory>
   ```

2. Open `index.html` in your preferred web browser:
   - Double-click the file, or
   - Use a local server (optional):
     ```bash
     # Using Python 3
     python3 -m http.server 8000
     
     # Using Node.js
     npx serve
     ```

3. Navigate to `http://localhost:8000` if using a local server
